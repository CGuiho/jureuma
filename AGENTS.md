# AGENTS.md

Instructions for AI agents working in the `jureuma` repository.

## Project

`jureuma` is an **agent-safe configuration CLI** written in Go under the GUIHO conventions (`juju` is an optional alias installed by `jureuma juju-enable`). Agent-safe means AI agents can use jureuma to set configuration and secrets and inject them into processes without ever seeing plaintext values.

- Each configuration is a pair plus a schema: `<stem>.unencrypted.json` (plaintext, human-owned, always gitignored), `<stem>.encrypted.json` (every value encrypted with X25519, field names readable, committed) and `<stem>.schema.json` or `.schema.jsonc` (JSON Schema draft 2020-12, generated by `jureuma schema infer` and refined by agents, committed). The default stem is `config`.
- `jureuma run -- <cmd>` injects the whole decrypted document, JSON-stringified, into `JUREUMA_` by default. `--format json|flatten|file` and `--env-name` change that. Child output is redacted.
- `decrypt`, `get`, `key show --private` and `key export` are human-only (terminal, no agent markers, typed confirmation word). `--dangerously-bypass-protections` is for humans who explicitly ask; it is audited.
- The CLI home is `~/.guiho/jureuma/`. Tests must set `JUREUMA_USER_HOME` (Go) or `HOME` (installer scripts) to a temporary directory and never touch the real home.
- Never put configuration values, plaintext or key material in any error message, log, test name or fixture output.

Behaviour is specified in [`docs/2026-10-13-jureuma-design.md`](docs/2026-10-13-jureuma-design.md). Package APIs are in [`docs/2026-10-13-jureuma-implementation-contracts.md`](docs/2026-10-13-jureuma-implementation-contracts.md). User documentation is in [`README.md`](README.md). The directory map is `xdocs tree`.

## Supported Format: JSONC

`jureuma` supports JSONC as defined by the [jsonc.org draft specification](https://jsonc.org/) (reference implementation: Microsoft `jsonc-parser`), in **lenient** mode:

- Base syntax is standard JSON (RFC 8259 / ECMA-404).
- `//` single-line and `/* */` multi-line comments are allowed wherever insignificant whitespace is allowed. Block comments do not nest. `#` comments are not supported.
- Trailing commas in objects and arrays are **accepted when reading** and **never emitted when writing**.
- Comments must not affect the data; removing them must yield the same values. When rewriting a file, preserve existing comments and formatting wherever possible.
- Preferred file extension is `.jsonc`; media type is `application/jsonc`.
- JSON5 features (unquoted keys, single quotes, hex numbers, `NaN`/`Infinity`, multiline strings) are out of scope.

### Agent Classes

#### Mastermind Agent

The Mastermind agent handles judgment. It is the strong model used for planning, architecture, spec review, plan review, self-review, and any ambiguous or high-risk decision during execution. It reads full repository context, resolves uncertainty with the safest reversible choice, and records the rationale to the question ledger (`docs/questions/`). Use a `mastermind` worker when correctness and reasoning matter more than speed or cost.

#### Workhorse Agent

The Workhorse agent handles labor. It is the efficient model used for well-specified implementation: code generation, refactors, schema changes, tests, and validation runs. It follows the plan unit exactly through `guiho-s-0440-hand-off`, using a capable authorized native agent whose actual child permissions cover the unit, and returns verified output for the executor to integrate. Use a `workhorse` worker when the task is mechanical and speed/cost matter more than deep reasoning.

#### Open Call — Custom Agents

Custom opencode agents are **`@`-mentionable subagents** ("open call"):

**UltraCode (`@ultracode`, `guiho-a-ultracode`)** is such a custom agent, and
it is defined. When CG invokes UltraCode — a standalone `UltraCode` /

Accepted marker forms are case-insensitive, one-word or two-word and need no

<task>` / `ultra code <task>`, the trailing marker `<task> Ultra Code` /
`<task> ultra code` / `<task> ultracode` where the preceding text supplies
the task — never a stale historic task — and optional trailing punctuation

UltraCode exists for speed through real parallel execution of independent

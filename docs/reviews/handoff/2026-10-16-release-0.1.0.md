## How To Run And Test It

Everything below is credential-free; use a sandbox home so nothing shared is
touched:

```sh
export TESTHOME=$(mktemp -d)
curl -fsSL https://raw.githubusercontent.com/CGuiho/jureuma/main/devops/install.sh | HOME="$TESTHOME" sh
export PATH="$TESTHOME/.guiho/bin:$PATH"

jureuma --version                       # prints: 0.1.0
mkdir -p "$TESTHOME/project" && cd "$TESTHOME/project" && git init -q .
jureuma init                            # keys, pair, schema, AGENTS.md block
printf '%s' "dummy-value" | jureuma set /apiKey --value-stdin
jureuma status && jureuma check
jureuma run -- sh -c 'printf "%s" "${JUREUMA_CONFIG:0:60}"'
jureuma upgrade check
```

For a real installation on your machine (README one-liner):

```sh
curl -fsSL https://raw.githubusercontent.com/CGuiho/jureuma/main/devops/install.sh | sh
```

Automated proof instead of manual steps: `runx run test-installers` runs the
whole lifecycle (install, catalog, upgrade, rollback, uninstall) hermetically
— 24 checks, all passing.
